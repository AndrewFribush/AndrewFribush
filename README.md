# Andrew Fribush

I'm a software and computer engineer working on production AI, data systems, and commerce. I've shipped production software since 2008.

For four and a half years I led engineering work at Abstract, including its production AI practice. My work has included multilingual speech pipelines, surgical-training assessment, storefronts, and the integrations behind them. I also cofounded [MemoryWell](https://technical.ly/startups/halcyon-sixth-cohort-fellows/).
